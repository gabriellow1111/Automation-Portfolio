Microsoft Power Automate Excel VBA Office 365 Process Optimization

Enterprise Notification Workflow Optimization

A client reached out to overhaul an existing Power Automate workflow managing weekly class schedules for corporate trainers. The original setup took over 30 minutes to run, stopped working after 256 rows, sent poorly formatted dates, and used hardcoded CC emails. I refactored the entire cloud flow and built a companion VBA pre-processing tool over live Zoom sessions.

Key Problems Solved

Dynamic Company-Based CCs

Previously, CC recipients were completely hardcoded. Built filtering logic that identifies the lead trainer's affiliated company and pulls all fellow trainers from that same organization onto the CC line automatically.

Row Pagination & Run Timeout

Power Automate's default Excel connector stopped reading after 256 rows, causing classes to disappear. Enabled pagination limits in settings and added OData filter parameters to ignore blank rows.

Date Formatting Bug

The external export sent dates as raw numerical serials or messy text strings. Implemented formatDateTime() expressions to standardize class timings cleanly.

Local VBA Pre-Processing Tool

Wrote an Excel VBA macro that takes the messy ERP export, removes junk columns, queries a reference file to tag trainer names to course codes, and prepares clean data ready for Excel Online in seconds.
