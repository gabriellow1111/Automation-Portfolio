Office Scripts TypeScript Excel on the Web

High-Volume Account Reconciliation & Dispatch Tool

An end-to-end automation workflow designed to parse high-volume statutory aging data, calculate multi-tier customer subtotals in memory, and generate customized notification emails.

The Tool in Action

Figure 1: Executing the Office Script on raw accounts aging export; generating grouped subtotals in under 3 seconds.

The Bottleneck

The operations team was manually downloading unformatted CSV extracts comprising thousands of aging records. Staff spent between 3 to 5 hours each reconciliation cycle manually applying VLOOKUP formulas, creating pivot tables, and copy-pasting customer figures into notification drafts.

Primary Risk: Manual formula modifications frequently introduced row-offset errors, leading to misstated customer balances during audits.

Engineering the Solution

Rather than relying on volatile spreadsheet formulas, the core processing engine was shifted into a cloud-native TypeScript Office Script:

1. In-Memory Array Batching

Avoided cell-by-cell DOM writes. The entire data range is pulled into memory as a 2D array, processed using hash maps to group accounts by client ID, and written back in a single batch call.

2. Dynamic HTML Email Generation

Querying specific site IDs cross-references an internal master roster to generate pre-styled HTML table summaries ready for outbound dispatch.
