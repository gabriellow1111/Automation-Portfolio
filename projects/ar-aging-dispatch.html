1. The Raw "Aging" Sheet

This is what the client started with—a massive sheet with dozens of irrelevant columns.

The actual data the team needed (Site Description, Due Date, Transaction Type, and Amount) was buried all the way out in columns 65 to 73.

2. One-Click Execution

Clicking "Run" executes the TypeScript logic directly in Excel on the Web.

The script clears out previous runs, skips hidden columns, filters 16 allowed invoice and credit types, adds sum formulas, and sets up formatting in roughly 15 seconds.

What the data looks like after the script finishes reorganizing it.

Each customer site gets its own clean table with light blue headers, dates sorted chronologically, formatted dollar values, and dynamic =SUM() rows at the bottom.

Where the team actually creates and sends client notifications.

Because the "Working" tab is cleanly structured, the Email Prep sheet simply references the site ID to pull in that customer's exact statement table—no manual copy-pasting required.

How It Works Under the Hood

Ignoring Hidden Columns

The script only targets columns 65 through 73, checking if a column is collapsed so it doesn't accidentally pull in hidden metadata that breaks the layout.

Filtering Transaction Types

There are lots of internal notes and noise in the raw file. The code checks each row against a list of 16 valid transaction types (like Lease Invoices, Credit Memos, and GIRO payments).

Sorting & Injected Sums

It sorts rows chronologically by Due Date, then writes an active =SUM() formula matching the exact row count for each customer site.

Fast In-Memory Processing

Instead of writing to Excel cell by cell (which freezes the browser), all filtering and math happen in memory first, then write to the sheet in a single batch.

Core TypeScript Logic

// Group rows by customer site and write dynamic SUM formulas
for (let site of uniqueSites) {
  let siteRows = data.filter(r => {
    let rType = String(r[txCol]).trim().toLowerCase();
    return String(r[siteCol]).trim() === site && allowedTypes.includes(rType);
  });

  if (siteRows.length === 0) continue;

  // Sort chronologically by due date
  siteRows.sort((a, b) => Number(a[dueColIndex]) - Number(b[dueColIndex]));

  headerRows.push(outputData.length);
  outputData.push(headers);
  let startRow = outputData.length;
  outputData.push(...siteRows);

  // Add the dynamic =SUM() formula row at the bottom of the group
  if (amountColIndex >= 0) {
    let firstRow = startRow + 1;
    let lastRow = startRow + siteRows.length;
    let colLetter = getColLetter(amountColIndex + 1);
    let sumRow = new Array(headers.length).fill("");
    sumRow[amountColIndex] = `=SUM(${colLetter}${firstRow}:${colLetter}${lastRow})`;
    outputData.push(sumRow);
    sumRows.push(outputData.length - 1);
  }
  outputData.push(new Array(headers.length).fill(""));
}
