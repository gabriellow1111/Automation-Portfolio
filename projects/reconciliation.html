The Operational Bottleneck

Reconciliation cycles previously required manual manipulation of static CSV dumps containing thousands of rows. Finance operators spent 3 to 4 hours per cycle building multi-level pivot tables, recalculating rolling 30/60/90+ day balances, and cross-referencing master account rosters manually.

Volatile Formula Offsets

Dynamic account additions frequently led to mismatched ranges, broken VLOOKUP dependencies, and corrupted audit logs.

Manual Dispatch Drafting

Operators had to manually inspect balances and compose individual notification emails for delinquent or anomalous site accounts.

Architectural Solution

Rather than relying on formula chaining or slow iterative spreadsheet API calls, the tool executes clean, in-memory aggregation via Office Scripts:

In-Memory Hash Map Grouping

Pulls data via a single getValues() call. Rows are mapped into TypeScript dictionary structures by Account and Site ID, eliminating repeated sheet DOM lookups.

Single Batch Writeback

Formatted summary structures, calculated subtotals, and status flags are committed in one transactional write operation, minimizing network overhead and API latency.
